# Framepillar

Framepillar is a desktop app for Windows and Mac that makes short looping videos for TikTok, Reels and YouTube Shorts with an AI you already pay for (Claude or Codex).

**Get the app, see the styles and pricing:** https://framepillar.com

**Learn how to use it:** https://framepillar.com/guide

**Questions or help:** https://framepillar.com/contact

## About this page

This repository only holds the installers that the website and the app's own updates download. The app's code is not here.

- Download the app from https://framepillar.com rather than from here: the site gives you the right file for your computer.
- "Source code" under each release is added by GitHub to every release. It only contains this README.
- Installed apps update themselves when a new version comes out.
